# 样式参数表（唯一权威：`scripts/filing_contract.py`）

数值单位：`sz`/`szCs` 为**半磅**；`w:ind`、`w:spacing`、`w:pgMar`、`w:trHeight` 为 **twips**（1/20 磅，567 twips = 1cm）；边框 `w:sz` 为**八分之一磅**；`w:fill` 为 RRGGBB。

来源标记：`[插件]` = IBD Tools normal.dotm 宏内定值；`[实证]` = 3-1/3-2/3-4 真实申报文件；`[插件=实证]` = 两者一致。

说明：

- `keep` = `keepNext` + `keepLines`。**标题必须 keepNext**，否则标题会留在上一页末行。
- `首行缩进 200 字符` 的 XML 需同时写 `w:firstLineChars="200"` 与 `w:firstLine="480"`（12pt 字号下 2 字符 = 480 twips）。3-1 实例中 002/003 用 `firstLine=200`，属半字符缩进的历史残留，**新文件按 480 写**。
- `行距 360 auto` = 1.5 倍行距。`单倍` = `w:spacing w:line="240" w:lineRule="auto"` 或不写 line。
- `段前 50 行` 的 XML 为 `w:beforeLines="50" w:before="50"`；换算成磅约 7.8pt（12pt 字号下 0.5 行）。

## 七、文字与数字规则（插件宏内实现的规范化）

| 规则        | 实现                                                                                 |
| --------- | ---------------------------------------------------------------------------------- |
| 中英标点转换    | `,→，` `.→。` `;→；` `:→：` `?→？` `!→！` `-→—` `~→～` `(→（` `)→）` `<→《` `>→》`，双引号按出现次序配对 |
| 数字内标点保留半角 | `([0-9])，([0-9])→\1,\2`；`.`、`．`、`—数字→-数字` 同理                                       |
| 千分位       | `Format(值, "#,##0.00;-#,##0.00; ")`，0 显示为空白                                        |
| 除以一万      | 值 / 10000，同样式；绝对值 < 0.01 → `-`                                                     |
| 百分比       | 文本末尾 `#` 后接 `%`；表格内直接 `InsertAfter "%"`                                            |
| 占比计算      | 单元格值 / 合计值，格式 `0.00%`                                                              |
| 圈码        | `①②③④⑤⑥⑦⑧⑨⑩` 直接键入                                                                  |
| 单位行       | `单位：万元` / `单位：元` / `单位：股`（右对齐、与下同页）                                                |
| 注释行       | `注：` 开头（两端对齐、无缩进）                                                                  |

## 八、定稿清理（等价插件"一键清理"）

1. `AcceptAllRevisions` + `TrackRevisions = False`
2. 删除全部批注（`Comments.DeleteRecursively`）
3. `TablesOfContents(1).UpdatePageNumbers`
4. `Content.HighlightColorIndex = wdNoHighlight`
5. `Content.Font.ColorIndex = wdBlack`
6. 楷体 → 宋体 + Times New Roman（`kaititosong`）
7. 页脚页码连续、无残留域

## 九、口径选择决策树

```
文件类型？
├─ 招股说明书 / 募集说明书        → profile 招股说明书，表格 threeline，标题用"标题 1..7"+自动编号
├─ 上市保荐书 / 证券发行保荐书 / 尽职调查报告
│                                  → profile 申报文件，表格 boxed，标题用 001..011 手写中文序号
├─ 发行保荐工作报告               → profile 申报文件（同上）
├─ 问询回复 / 反馈回复             → profile 回复报告，表格 threeline，标题用"问题 N"+自动编号
└─ 新三板申报文件                 → profile 新三板，正文与表内均 21（五号），表格 boxed
```

跨类型混用时以**该份文件首页页眉的文件全名**为准（例如"之上市保荐书"→ 申报文件口径）。
